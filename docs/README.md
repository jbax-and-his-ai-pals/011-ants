## Editing policy

Update the document that owns the fact. Add a focused report only when a substantial experiment needs its own methods/results; link it here. Keep dated measurements and old suite counts labeled as evidence. Update the Roadmap when selecting or completing work, and do not present proposals as shipped features. Validate local links after renaming documents.
